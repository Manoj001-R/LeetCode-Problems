# LeetCode Solutions

A collection of LeetCode problem solutions organized by difficulty. Solutions are stored in individual files within `Easy`, `Medium`, and `Hard` folders.

## Structure

- `Easy/` – Easy difficulty problems
- `Medium/` – Medium difficulty problems
- `Hard/` – Hard difficulty problems

## Languages Used

- Python
- Java *(select problems)*

## Getting Started

1. Clone or open the repository in your preferred editor.
2. Navigate to the desired difficulty folder.
3. Run any solution file with Python:

```bash
python Easy/Two_Sum.py
```

## Conventions

- File names use the problem title with underscores replacing spaces.
- Each solution is written as a self-contained script.
